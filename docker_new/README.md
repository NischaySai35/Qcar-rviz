Esync sdk for RPI board:
1. Before installing sdk ensure the date is correct on hardware
2. To install esync run the script install_esync.sh
   
   Help Options : 
Usage options :

./install_esync.sh <... options ...>

Install options :
           -i           # To install eSync.
           -u           # To Uninstall eSync.

Other options :
           -h           # Help / Usage Options

  E.g., './install_esync.sh -i
